Improve the Tenant Scan Results page and add PDF report export.

Current issues:
1. The scan results page says “21 CMMC Controls evaluated.” That is misleading.
2. There is no PDF report export available.
3. The tenant scan should clearly distinguish between:
   - controls touched by Microsoft Graph data
   - controls fully assessed
   - controls requiring manual review
   - full CMMC Level 2 scope of 110 controls

Fix these items.
