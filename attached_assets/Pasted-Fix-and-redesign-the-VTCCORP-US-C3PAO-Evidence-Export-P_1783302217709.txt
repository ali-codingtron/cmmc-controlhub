Fix and redesign the VTCCORP.US C3PAO Evidence Export Package.

I reviewed the generated ZIP:

VTCCORP.US_C3PAO_Evidence_Package_2026-07-06.zip

The package is close, but it is not C3PAO-friendly enough yet and it is missing important document content.

Current issues:
1. Package metadata shows documents = 0.
2. 05_All_Documents only contains Document_Inventory.xlsx, and the inventory is empty.
3. Control folders do not contain Documents folders.
4. Policies/procedures that are uploaded as evidence are not being included in the Documents section.
5. 04_All_Evidence does not include all 1,061 evidence files.
6. Domain folders use names like ACCE, SYST, IDEN, CONF instead of CMMC domain codes AC, SC, IA, CM, etc.
7. Some exported filenames are too long and truncated.
8. Monitoring_Tracker.xlsx has blank task/title values.
9. The package structure is not ideal for a C3PAO that may need to manually import evidence into their own repository.

Goal:
Create a cleaner, assessor-friendly and import-friendly C3PAO export package that includes all documentation, evidence, mappings, SSP, monitoring, POA&M, and reports in a format that is easy for a C3PAO to review or upload into their own system.

10. FIX FILENAMES AND PATH LENGTH
====================================================================

Current filenames are too long and sometimes truncated.

Use clean, short, consistent filenames.

Suggested format:

CONTROLID__TYPE__SHORT_TITLE__YYYY-MM-DD.ext

Examples:
AC.L1-3.1.1__Screenshot__All_Users__2026-05-05.png
IA.L2-3.5.3__Policy__MFA_Conditional_Access__2026-05-05.png
AU.L2-3.3.5__Log__Audit_Log_Review__2026-06-23.pdf
CA.L2-3.12.2__POAM__POAM_Register__2026-07-06.xlsx

Rules:
- Replace dots in folder names only if needed, but keep control ID readable.
- Remove unsafe characters.
- Keep filenames under 120 characters.
- Keep full path under 200 characters where possible.
- Avoid unnecessary repeated title/date/original filename.
- Preserve original extension.
- If duplicate filename exists, append _01, _02.

Add original filename to manifests so nothing is lost.
