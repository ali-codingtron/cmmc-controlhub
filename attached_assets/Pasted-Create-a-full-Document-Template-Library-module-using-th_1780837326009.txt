4. Control ID Mapping

The package maps controls as NIST-style numbers like:

3.1.1
3.1.2
3.5.3
3.14.7

The app uses CMMC control IDs like:

AC.L1-3.1.1
AC.L2-3.1.3
IA.L2-3.5.3
SI.L2-3.14.7

Map imported template controls to existing global Control records.

Do not create duplicate controls.

Mapping logic:
- match by NIST/control number suffix first
- match family/domain to determine correct CMMC prefix
- if control is Level 1, map to L1 control ID
- if control is Level 2, map to L2 control ID
- if ambiguous, flag for manual review

Examples:
3.1.1 → AC.L1-3.1.1
3.1.3 → AC.L2-3.1.3
3.5.3 → IA.L2-3.5.3
3.14.7 → SI.L2-3.14.7
