Update the Edit Organization Profile feature so ONLY users with the platform-level Global Admin role can make changes.

This requirement is strict.

====================================================================
GLOBAL ADMIN-ONLY EDITING
====================================================================

Only a user whose authenticated platform role is:

GLOBAL_ADMIN

may:

- see the Edit Profile action
- open the editable Organization Profile form
- submit profile changes
- change organization name
- change legal name
- change short name
- change CAGE code
- change UEI
- change industry
- change primary contact information
- change address
- change assessment-scope description
- change organization logo
- change profile notes

No organization-specific role may edit an organization profile.

The following roles must not be allowed to edit organization profiles:

- Organization Admin
- Compliance Manager
- IT Contributor
- Reviewer
- Executive Viewer
- Assessor Read-Only
- Demo Viewer

This restriction applies even when an Organization Admin is assigned to the organization being viewed.

====================================================================
UI BEHAVIOR
====================================================================

For Global Admin:

- show Edit Profile on organization cards
- show Edit Profile on the organization detail page
- allow access to the editable profile form
- show Save Changes

For all non-Global Admin users:

- hide Edit Profile
- hide Save Changes
- do not render editable fields
- show organization profile information as read-only where existing permissions allow
- do not show disabled editing controls that imply the user may request access

The read-only profile may display:

- Organization Name
- Legal Name
- Short Name
- CAGE Code
- UEI
- Industry
- Primary Contact
- Address
- Assessment Scope
- Compliance Configuration

But no non-Global Admin user may modify these values.

====================================================================
BACKEND AUTHORIZATION
====================================================================

Do not rely only on hiding the Edit Profile button.

Every organization-profile update API must verify:

authenticatedUser.platformRole === GLOBAL_ADMIN

Example:

PATCH /api/organizations/:organizationId/profile

Authorization:

1. Confirm the user is authenticated.
2. Load the user’s platform role from the authoritative backend source.
3. Confirm platform role equals GLOBAL_ADMIN.
4. If not, return HTTP 403.
5. Do not use organization membership role as a substitute.
6. Do not trust a platform-role value supplied by the browser.

Organization Admin membership must not grant profile-edit permission.

Compliance Manager membership must not grant profile-edit permission.

Use a dedicated capability if the application uses capability checks:

organizations.profile.edit

Assign this capability only to:

GLOBAL_ADMIN

Do not assign it to any organization role.

====================================================================
DIRECT-URL AND API PROTECTION
====================================================================

A non-Global Admin must not be able to edit a profile by:

- entering the edit URL manually
- modifying frontend state
- changing an API request
- using browser developer tools
- calling the PATCH endpoint directly
- impersonating an organization role

Expected behavior:

- editable route returns a controlled unauthorized response or redirects to the read-only profile
- PATCH request returns HTTP 403
- no fields are changed
- unauthorized attempt is audit logged

Error message:

“You do not have permission to edit organization profiles. This action is restricted to Global Administrators.”

====================================================================
GLOBAL ADMIN IDENTIFICATION
====================================================================

Use the platform-level role as the authoritative source:

platform_role = GLOBAL_ADMIN

Do not authorize profile editing based on:

- legacy role
- Organization Admin membership
- current organization role
- role badge displayed in the frontend
- the selected organization
- a client-supplied role value

The break-glass System Administrator account may edit organization profiles because it is a platform-level Global Admin.

Do not alter the break-glass account’s authentication or protection settings.
