Add an Automated Baseline Assessor module.

Purpose:
I do not want to manually assess 110 controls one by one.

The system should assess an organization by implementation area, uploaded evidence, documents, SSP content, POA&M data, and monitoring tracker data.

The goal is to quickly determine:
- current readiness
- likely implemented controls
- partially implemented controls
- missing evidence
- missing documents
- missing SSP narratives
- monitoring gaps
- POA&M candidates
- recommended next actions

Important:
This is an internal readiness assessor, not an official C3PAO certification tool.

The module should generate recommended findings and suggested statuses, but it should require Admin or Compliance Manager approval before changing actual control statuses.

3. Assessment Intake Wizard

The assessment should start with a guided intake wizard.

Ask organization-level questions first:

- Is an SSP uploaded?
- Is the assessment scope defined?
- Are in-scope assets documented?
- Is CUI stored, processed, or transmitted?
- Are users and privileged users documented?
- Are policies uploaded?
- Are procedures uploaded?
- Is evidence already uploaded?
- Is a POA&M available?
- Is a monitoring tracker active?
- Are endpoints centrally managed?
- Is MFA enforced?
- Are audit logs reviewed?
- Are vulnerabilities reviewed?
- Are backups tested?
- Has incident response been tested?

Answer options:
- Yes
- No
- Partial
- Unknown
- Not Applicable

Each answer should support:
- notes
- upload evidence
- link existing evidence
- create evidence request
- create POA&M
- assign owner

5. Uploaded Document/Evidence Analysis

Add an “Analyze Uploaded Artifacts” function.

When I upload or already have documents/evidence, the system should suggest:

- likely document type
- likely evidence type
- related control IDs
- related domain
- whether it supports policy/procedure/evidence
- missing metadata
- suggested assessor summary
- suggested filename if current name is weak

Examples:
- A file named “MFA Policy Screenshot.png” should suggest IA.L2-3.5.3 and AC.L2-3.1.13
- A document named “Access Control Policy.docx” should suggest AC controls
- A “Risk Register.xlsx” should suggest RA.L2-3.11.1 and CA.L2-3.12.2
- A “POA&M.xlsx” should suggest CA.L2-3.12.2

Do not automatically apply mappings without confirmation.
Show suggested mappings and allow user to approve/reject.

8. Rules Engine

Create a rules engine that determines suggested readiness.

For each control, suggested status should be:

Not Started:
- no evidence
- no documentation
- no SSP narrative
- no positive assessment answers

In Progress:
- partial evidence exists
- or documentation exists but no test/evidence
- or answers are Partial

Needs Evidence:
- user says implemented
- but no approved evidence exists

Needs Documentation:
- evidence exists
- but policy/procedure is missing

Needs Validation:
- evidence and documentation exist
- but no test/validation is recorded

Candidate for Implemented:
- SSP narrative exists
- approved evidence exists
- required policy/procedure exists if applicable
- test/validation exists if applicable
- no blocking POA&M exists

Implemented:
- only after user approves suggested status

9. Confidence Score

For each control and assessment pack, calculate a confidence score.

Suggested formula:
- 25% implementation answer
- 20% approved evidence
- 15% SSP narrative
- 15% required policy/procedure
- 10% test/validation
- 10% monitoring current if applicable
- 5% no blocking POA&M

Show:
- High Confidence
- Medium Confidence
- Low Confidence
- Unknown

10. Projected Score

Generate an internal projected CMMC score.

Important:
Label it:
Projected Internal Readiness Score

Do not label it as an official CMMC score.

For Level 2:
- max score = 110
- subtract point values for controls assessed Not Met
- use 1 / 3 / 5 point values if stored
- if point values are not stored yet, add control_score_weight to the Control model

Show:
- projected score
- controls likely met
- controls partially met
- controls not met
- controls unknown
- POA&M candidates
- blocking gaps
