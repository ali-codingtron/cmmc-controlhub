Add a new module called “Tenant-Connected Pre-Assessment.”

Purpose:
I want Control HUB to connect to an organization’s Microsoft 365 / Entra / Intune / Defender tenant in read-only mode and perform an automated CMMC readiness pre-assessment.

This is NOT an official C3PAO assessment.
This is an internal current-state pre-assessment that helps determine where an organization currently sits before implementation work begins.

The module should:
- connect to a Microsoft tenant
- pull configuration and posture data
- map data to CMMC controls
- generate findings
- generate evidence requests
- recommend implementation roadmap actions
- produce a pre-assessment report
- avoid making any changes to the Microsoft tenant

Do not build remediation/write-back yet.
This must be read-only.

3. Authentication Model

Use Microsoft identity platform / Microsoft Graph.

Support two modes:

A. Delegated Assessment Mode
- user signs in with Microsoft admin account
- app reads only what that user is authorized to read
- good for quick assessments

B. App-Only Assessment Mode
- tenant admin grants application permissions
- app can run scheduled/background scans
- good for repeat assessments

Use MSAL or Microsoft-supported authentication library.

Do not store Microsoft admin passwords.

Store tokens/secrets securely.
Encrypt any refresh tokens or credentials at rest.
Allow tenant disconnect/revoke.

11. CMMC Mapping

Each automated rule should map to:
- domain
- control IDs
- support type:
  - Strong Evidence
  - Partial Evidence
  - Configuration Indicator
  - Needs Human Review
  - Not Sufficient Alone

Example:
MFA registration data is strong technical evidence for MFA posture, but the app should still require policy/procedure and validation before marking IA.L2-3.5.3 implemented.

12. Automated Classification

After scan, classify controls as:

Likely Implemented:
- technical data strongly supports implementation
- approved policy/procedure exists
- SSP narrative exists
- no critical gap detected

Partially Implemented:
- technical control exists but missing evidence/documentation/testing

Needs Evidence:
- data suggests control is configured
- but no approved evidence exists in Control HUB

Needs Documentation:
- technical data exists
- but policy/procedure missing

Needs Validation:
- configuration exists
- but testing/review evidence missing

Not Implemented:
- technical data shows control missing

Unknown:
- data source unavailable
- permission missing
- control cannot be assessed from Microsoft tenant alone

19. Security Requirements

This integration handles sensitive tenant data.

Implement:
- read-only Graph permissions only
- admin consent screen
- least privilege permission groups
- encrypted token/secret storage
- tenant disconnect
- audit logs for every scan
- audit logs for preview/download/export
- no password collection
- no write-back to Microsoft tenant
- no automatic remediation
- no sharing data across organizations

20. Error Handling

- retry with backoff
