Redesign ONLY the unauthenticated Control HUB login page.

Current page:

- split-screen layout
- dark navy product panel on the left
- login form on the right
- local username/password login
- password reset link
- Microsoft sign-in
- Carme Technology / Control HUB branding

Goal:

Create a polished enterprise SaaS login screen that clearly communicates:

- Carme Technology branding
- Control HUB product identity
- compliance readiness and evidence management
- local sign-in
- Microsoft sign-in
- secure authorized access

This is primarily a user-interface and user-experience improvement.

Do not change authentication behavior unless specifically required below.

====================================================================

Remove the current four tiles:

- 110+ Controls Tracked
- 14 CMMC Domains
- Multi Evidence Types
- Always Audit Ready

Reasons:

- CMMC Level 1 does not use the same requirement count as Level 2.
- Control HUB supports multiple packages, including NIST and DFARS.
- “Always Audit Ready” is an absolute claim and should not be displayed.

Replace them with three package-neutral value statements:

- Multi-Framework Management
  “Manage CMMC, NIST, DFARS, and applicable organizational requirements.”

- Evidence Mapped to Requirements
  “Organize supporting artifacts and maintain clear requirement traceability.”

- Controlled Workflows and Audit History
  “Use role-based workflows, approvals, monitoring, and recorded activity.”

Use compact icon-and-text rows rather than four large metric cards.

Do not hardcode framework control counts on the public login page.

====================================================================

- logical tab order

15. SECURITY-SENSITIVE UI BEHAVIOR
====================================================================

- not store passwords in browser storage
- not write credentials to console logs

- preserve email only when safe and useful
- show a Caps Lock indicator when detectable
- use HTTPS-only production URLs

Do not add “Remember Me” unless the existing session design securely supports it.
