Build an internal-only CMMC compliance readiness and evidence management web app for my team.

This is not a public SaaS product. It is an internal tool used by me and my team to manage CMMC Level 1 and Level 2 readiness, evidence, recurring reviews, dashboards, and assessor-facing documentation.

Use a practical stack suitable for Replit:
- Next.js or React frontend
- Node.js backend
- PostgreSQL database
- Prisma ORM
- Role-based access control
- Local/internal authentication
- File upload support
- Background jobs or scheduled task logic for reminders

Core goal:
Create an internal compliance operations platform where we can track CMMC L1/L2 controls, upload evidence, label documents correctly, monitor compliance progress, and prepare documentation for a C3PAO assessor.

Build the app around these modules:

Create dashboards showing:
- Overall CMMC readiness score

11. Readiness Logic
Implement basic scoring logic.

A control should be:
- Not Started if it has no evidence and no tasks completed
- In Progress if it has some evidence or open tasks
- Needs Review if evidence exists but is not approved
- Implemented if required evidence exists and is approved
- Assessor Ready if evidence is approved, current, mapped to assessment objectives, and has an assessor summary
- At Risk if evidence is stale, reviews are overdue, or POA&M items are open

Domain readiness should be based on the percentage of controls that are implemented or assessor-ready.

Dashboard score should be calculated from:
- control status
- evidence completeness
- evidence freshness
- overdue tasks
- open POA&M items
- missing procedures
- missing policies

13. Automation Rules
Implement or stub these automation rules:

- When evidence is uploaded without a linked control, mark it needs_classification
- When evidence is uploaded with all required metadata, allow submit for review
- When evidence is approved, update linked control scoring
- When evidence expires, mark it stale
- When evidence is superseded, keep old version but remove it from active assessor package
- When a task due date passes, mark it overdue
- When a recurring task is completed, create the next task
- When a control has no evidence, show it on missing evidence dashboard
- When a control has stale evidence, mark the control at risk
- When a POA&M item is open, reduce readiness score for linked control
- When all required evidence is approved and current, mark control implemented
- When implementation narrative and assessor summary exist, allow assessor_ready status
- When evidence is rejected, notify owner and require notes
- When control status changes, write audit log
- When evidence is downloaded, write audit log
- When assessor package is exported, write audit log
- When policy review is due in 14 days, show reminder
- When access review is overdue, escalate to Compliance Manager
- When training record expires, create review task
- When backup review is missed, create high-priority task
