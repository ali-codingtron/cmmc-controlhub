Fix the All Documents page so uploaded policy/procedure evidence appears there too.

All Documents should show both:
1. Documents generated from templates
2. Uploaded evidence items that are document-like, such as Policy, Procedure, Log, Report, Checklist, Register, Training Record, Incident Record, Risk Record, Supplier Review, Backup Verification, Vulnerability Scan, etc.

Update All Documents to include:
- records from Document table
- uploaded Evidence records where evidence_type is document-like

At minimum include evidence types:
- Policy
- Procedure
- Log
- Report
- Access Review
- Training Record
- Incident Record
- Risk Record
- Approval Record
- System Inventory
- Asset Inventory
- Supplier Review

All Documents table/cards should show:
- Title
- Type
- Status
- Linked Controls
- Security Domain
- CMMC Level
- Owner
- Uploaded/Created Date
- Review/Expiration Date
- Source: Generated Document or Uploaded Evidence

- security domain code
- security domain name
- CMMC level
- control ID
- organization ID

If policy evidence is linked to AC.L1-3.1.1, show tags:
- Access Control
- AC
- L1
- AC.L1-3.1.1
- Policy

4. Add/Edit Evidence Tagging
On Add/Edit Evidence, show metadata fields:
- Evidence Type dropdown
- Linked Control dropdown/multi-select
- Security Domain auto-filled from linked control
- CMMC Level auto-filled from linked control
- Tags field
- Owner
- Review Date
- Expiration Date
- Assessor Summary

If multiple controls are selected, show all related domains and levels.

If the item is uploaded evidence, clicking it from All Documents should open either:
- the Evidence Detail page
or
- a unified Document Detail page that clearly says Source = Uploaded Evidence

It must show:
- uploaded file link
- linked controls
- security domains
- level
- status
- owner
- review/expiration dates
- tags
- audit history

Uploaded evidence of type Policy or Procedure must count toward documentation gap analysis once status is Approved, Active, or Assessor Ready.

Draft policy/procedure evidence should show as:
“Policy exists but not active”
or
“Procedure exists but not active.”
