Add a C3PAO Evidence Export Package feature for VTCCORP.US.

Purpose:
VTCCORP.US is preparing for a C3PAO audit. The C3PAO may require us to upload all evidence and documentation into their own repository instead of reviewing it directly inside Control HUB.

I need Control HUB to generate a complete export package containing all audit-ready documentation, evidence, SSP data, monitoring records, POA&M items, and reports in a clean folder structure that can be uploaded to the C3PAO’s system.

This should be organization-specific.

Initial organization:
VTCCORP.US

1. Add Export Package Feature

Add an admin-only feature called:

C3PAO Export Package

Location:
Reports > C3PAO Export Package

or Admin utility:
Admin > Export Package

The package should generate a ZIP file.

File name:
VTCCORP.US_C3PAO_Evidence_Package_YYYY-MM-DD.zip

Before generating, allow options:

Organization:

Include only Approved, Active, and Assessor Ready items.

4. Control Package Contents

For each CMMC control folder, include:

- Control_Summary.pdf
- Implementation_Narrative.txt
- SSP_Narrative.txt
- linked evidence files
- linked policy/procedure documents
- linked monitoring records
- linked POA&M items if any

Control_Summary.pdf should show:
- control ID
- control title
- domain
- level
- implementation status
- implementation narrative
- SSP narrative
- evidence list
- document list
- monitoring items
- POA&M status
- assessor notes if available

5. Evidence File Naming

When exporting evidence files, rename copies using a clean audit-friendly naming format.

Format:
CONTROLID_EVIDENCETYPE_TITLE_DATE_ORIGINALFILENAME

Example:
AC.L1-3.1.1_Screenshot_User_Access_Review_2026-06-23_R-01_All_Users.png

Rules:
- do not change original file in the app
- only rename the exported copy
- remove unsafe characters
- keep original extension
- avoid duplicate filenames by appending _01, _02, etc.

6. Documents

Include all approved/active documents linked to controls.

Documents should include:
- policies
- procedures
- logs
- review records
- approval records
- generated documents
- uploaded documents
- document-like evidence

Do not include internal-only drafts unless selected.

11. Missing Files Handling

If an evidence record exists but the file is missing from storage:
- do not fail the entire export
- include it in Export_Issues.xlsx
- mark as “metadata exists, file missing”
- include evidence title, linked controls, and original file path/storage key
- show warning after export

Only Global Admin or Organization Admin should generate this package.

Do not expose export package publicly.

- API keys
- passwords

- demo data
