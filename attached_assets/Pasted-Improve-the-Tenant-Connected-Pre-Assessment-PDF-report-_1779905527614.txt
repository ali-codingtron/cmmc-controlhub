Improve the Tenant-Connected Pre-Assessment PDF report again.

The current report is better, but it still looks like a technical export instead of a polished professional client deliverable.

Goal:
Make the report look and read like a professional CMMC pre-assessment report that I can give to a client executive, business owner, or technical lead.

Do not remove the technical detail, but organize it better.

1. Create Two Report Modes

Add two PDF report options:

A. Executive Pre-Assessment Report
Audience:
- business owner
- executive
- client stakeholder

Length:
- 4 to 6 pages

Focus:
- where the organization stands
- top risks
- business impact
- recommended next steps
- 30/60/90 day action plan

B. Technical Pre-Assessment Report
Audience:
- IT admin
- compliance manager
- technical remediation team

Length:
- as long as needed

Focus:
- findings
- evidence requests
- Graph data summaries
- permission diagnostics
- control mappings
- roadmap details

The current report is trying to do both at once. Split the experience.

Use this exact structure:

Page 1: Cover Page
- Control HUB logo

Add a plain-English interpretation box:
“What This Means”

Example:

Page 3: Top Risks and Immediate Actions
Show only the top 5 risks.

Columns:
- Priority
- Risk / Gap
- Why It Matters
- Recommended Action
- Related Controls
- Owner
- Target Date

Organize roadmap into:
- First 30 days

- evidence to collect
- estimated effort
- recommended owner

Page 5: Assessment Coverage and Limitations
Show:
- what Microsoft tenant scan evaluated
- what still requires manual review
- controls touched by scan

- explanation that this is not a full CMMC assessment

Page 6: Appendix Summary
Brief technical appendix reference:
- findings count

- permission/data availability notes
