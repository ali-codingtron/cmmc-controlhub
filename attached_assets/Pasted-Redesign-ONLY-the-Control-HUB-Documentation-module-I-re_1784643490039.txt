Redesign ONLY the Control HUB Documentation module.

I reviewed the current Documentation workflow and uploaded the following example package:

Docs for Templates in Control Hub.zip

The ZIP contains professional policies, procedures, plans, assessments, matrices, registers, diagrams, and an SSP. Use these documents as the design and formatting benchmark for documents generated by Control HUB.

Core design decision:

Documentation must become a controlled-document generation center.

It should not be a second file repository.

The Evidence Repository and the Evidence tabs under Controls will remain the authoritative location for generated and uploaded documents.

12. COMMON PROFESSIONAL FORMATTING
====================================================================

All generated documents should use consistent professional styling.

Default font:

- Calibri or organization-selected approved font
- body text: 10.5 or 11 point
- table text: no smaller than 9 point unless necessary for a landscape matrix
- title: approximately 26–32 point
- Heading 1: approximately 18–22 point
- Heading 2: approximately 14–16 point

Default theme:

- dark navy headings
- professional blue table headers
- light blue or gray secondary header cells
- white body background
- restrained use of color
- no bright or generic web styling

Cover page should support:

- organization logo
- document title
- subtitle
- document number
- revision
- revision date
- classification banner
- organization legal name
- address
- optional CAGE/UEI

Headers:

- document number
- document title or assessment-support label

Footers:

- organization name
- confidentiality / controlled-document notice
- page number
- optional “Page X of Y”

Example controlled-document footer:

“Controlled Document — Uncontrolled When Printed”

Tables:

- consistent borders
- bold table headings
- repeating header rows
- readable cell padding
- vertical alignment
- no text clipping
- no rows split unnecessarily
- landscape orientation for wide tables

Document navigation:

- automatic or materialized table of contents
- numbered headings
- page breaks before major sections
- bookmarks/internal links where supported

Do not use unresolved raw Markdown.

Do not output raw JSON.

Do not produce generic two-page documents that ignore the template’s intended structure.
