Repair and complete ONLY the Tasks tab under Control Detail.

I provided a video showing the current behavior.

Current workflow:

1. A user opens a control.
2. The user selects the Tasks tab.
3. The user clicks Add Task.
4. The user enters:
   - Title
   - Description
   - Priority
   - Due Date
5. The task saves successfully.
6. The task appears as a summary card showing:
   - Title
   - Open status
   - Priority
   - Due Date

Current problems:

- The saved task cannot be opened.
- Clicking the task does nothing.
- The description entered during creation is no longer visible.
- There is no View Task action.
- There is no Edit Task action.
- There is no way to change the assignee.
- There is no way to move the task to In Progress.
- There is no way to mark the task Blocked.
- There is no way to close the task.
- There is no way to reopen a closed task.
- There is no task activity/history view.
- There is no clear filtering between active and closed tasks.
- There is no clear record of who created, updated, or closed the task.

Goal:

Turn the Tasks tab into a reliable control-level task-management workflow while preserving the existing task data.

A task should remain linked to one organization and one control.

====================================================================
19. TRANSACTIONAL UPDATES
====================================================================

Every lifecycle action should be transactional.

Example Close Task:

1. Verify authorization.
2. Load the task by organization, control, and task ID.
3. Verify it is not already Closed or Cancelled.
4. Validate closure summary.
5. Update task status and closure fields.
6. Create activity/audit record.
7. Commit.
8. Return canonical task.

If any step fails:

- roll back all changes
- preserve previous task state
- return a clear error

Do not leave a task closed without a closure record.
