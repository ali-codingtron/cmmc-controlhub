17. PLACEHOLDER PROCESSING
====================================================================

Build a robust DOCX placeholder engine.

It must replace placeholders in:

- body paragraphs
- tables
- nested tables
- headers
- footers
- captions
- text boxes, where supported
- repeated requirement sections

It must support placeholders that Word has split across multiple XML runs.

Do not use a simple one-run string-replacement method.

The engine should:

1. Load a copy of the master template.
2. Discover all `{{PLACEHOLDER}}` tokens.
3. Reconstruct tokens split across runs.
4. Replace the token while preserving surrounding formatting.
5. Insert multiline text safely.
6. Insert images for approved image placeholders.
7. Preserve tables, page breaks, headers, footers, orientations, and styles.
8. Validate that the DOCX opens.
9. Report unresolved placeholders.
10. Never modify the master template.
