Fix and redesign the Tenant-Connected Pre-Assessment PDF report.

Current report issues observed:
1. The report creates unnecessary blank/spacer pages that only show the header/footer.
2. The PDF looks like a raw browser printout instead of a professional consulting deliverable.
3. The appendix has broken characters/icons, such as "' Available" and "' Unavailable".
4. The report says “Controls Touched” but the count must be consistent with the scan results page.
5. Device / Intune Pack is marked failed, but Intune evidence snapshots still appear as if they are normal pending evidence.
6. Findings, evidence requests, and roadmap items are text-heavy and not visually organized enough.
7. Tables need better formatting, page breaks, section spacing, and consistent styling.

Fix this report generation completely.

1. Use a Dedicated PDF Template

Do not generate the PDF by simply printing the live web page.

Create a dedicated report template specifically for PDF output.

Preferred approach:
- server-side HTML-to-PDF using Playwright/Puppeteer
OR
- a proper PDF generation library

The PDF should not include:
- browser chrome
- web scrollbars
- raw page layout artifacts
- empty pages
- broken Unicode icons
- cut-off tables

2. Remove Blank Pages

Fix page break CSS.

Check for bad CSS such as:
- page-break-after: always on every section
- break-after: page on empty containers
- min-height: 100vh
- height: 100vh
- oversized margins
- empty report sections that still force a new page

Rules:
- Only force page breaks before major sections when needed.
- Do not create a page unless there is content.
- Use break-inside: avoid for cards/tables.
- Do not split headings from the content below them.
- Do not split table headers from rows.

Acceptance:
The report should not have pages that only contain:
“Control HUB — Tenant-Connected CMMC Pre-Assessment Report Page X”
with no report content.

3. Fix Header and Footer

Use a professional repeating header/footer.

Header:
- Control HUB logo
- Report title
- Organization name
- Scan date

Footer:
- Confidential — Prepared by Control HUB
- Not an official CMMC assessment
- Page X of Y

Make sure the footer does not create extra blank pages.

4. Fix Broken Icons / Characters

The appendix currently shows broken characters like:
- "' Available"
- "' Unavailable"

Replace icon glyphs with safe text labels or styled badges.

Use:
- Available
- Unavailable
- Missing
- Granted
- Not Granted

Do not use emojis or special symbols unless the PDF renderer embeds fonts correctly.

5. Make Counts Consistent

Use one backend report data source for both:
- scan results page
- PDF report

The report should match the UI exactly.

Fix these values:
- Tenant Scan Health
- Assessment Confidence
- Controls Touched by Tenant Scan
- Checks Run
- Passed
- Gaps Found
- Unknown / No Data
- Findings
- Evidence Snapshots
- Evidence Requests

If the UI says 21 controls touched, the PDF should say 21.
If the PDF says 25 controls touched, the UI should say 25.
Do not calculate this separately in two places.

Add supporting note:

Do not use:
“CMMC Controls Evaluated”
