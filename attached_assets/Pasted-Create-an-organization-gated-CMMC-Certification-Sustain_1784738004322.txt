Create an organization-gated CMMC Certification & Sustainment module.

Important terminology:

Do not call this a “C3PAO Certification” module.

The organization receives a Conditional or Final Level 2 (C3PAO) CMMC Status after an assessment performed by a C3PAO.

Module name:

CMMC Certification & Sustainment

Sidebar label:

Certification

Purpose:

This module becomes available only after an organization records and verifies an official Conditional or Final Level 2 (C3PAO) CMMC Status.

It is used to preserve the official assessment record, track annual affirmations, maintain the certified scope, evaluate changes, complete a Conditional POA&M, and prepare for recertification.

====================================================================
1. PRODUCTION SAFETY
====================================================================

Do not activate this module for any existing organization.

Do not change:

- organization data
- controls
- evidence
- documents
- SSP
- POA&M
- monitoring
- reports
- roles
- users
- current navigation
- current assessment modes

Add the module in a disabled state.

All existing organizations should default to:

certification_module_state = NOT_AVAILABLE

No current production organization should see the new sidebar item until an authorized activation is completed.

====================================================================
2. ORGANIZATION CERTIFICATION STATES
====================================================================

Add an organization certification state:

- NOT_AVAILABLE
- VERIFICATION_PENDING
- CONDITIONAL_L2_C3PAO
- FINAL_L2_C3PAO
- EXPIRED
- SUSPENDED
- INVALIDATED
- ARCHIVED

Default:

NOT_AVAILABLE

Behavior:

NOT_AVAILABLE:
- Certification sidebar item hidden
- certification routes unavailable

VERIFICATION_PENDING:
- sidebar hidden from normal users
- verification page visible only to users with certification.verify permission

CONDITIONAL_L2_C3PAO:
- Certification sidebar item visible
- amber status
- POA&M Closeout tab visible

FINAL_L2_C3PAO:
- Certification sidebar item visible
- green status
- POA&M Closeout tab hidden unless historical closeout data exists

EXPIRED:
- module remains available for historical review
- red Expired status
- no active-certification claims

SUSPENDED or INVALIDATED:
- module visible only to authorized users
- prominent warning
- retain history and records

ARCHIVED:
- hidden from normal navigation
- retained for authorized historical access

3. ACTIVATION WORKFLOW
====================================================================

Do not use a simple checkbox.

Add:

Organization Settings > Certification Status

Button:

Record CMMC Certification Status

Step 1 — Status:

- Conditional Level 2 (C3PAO)
- Final Level 2 (C3PAO)

Step 2 — Official Assessment Details:

Required fields:

- CMMC UID
- Assessment Level
- C3PAO Name
- CMMC Status Date
- Assessment Start Date
- Assessment Completion Date
- Assessment Unique Identifier
- CAGE Codes
- Assessment Scope Name
- SSP Title
- SSP Version
- SSP Date
- Affirming Official
- Internal Certification Owner

Optional fields:

- assessor names
- assessor business contact information
- contract references
- notes

Step 3 — Supporting Records:

Require at least one appropriate official record:

- CMMC Assessment Findings Report
- official status confirmation
- authorized SPRS status verification
- certification record, if issued
- POA&M closeout result, if applicable

Optional:

- artifact hash manifest
- final scope package
- final SSP
- assessment correspondence

Step 4 — Verification:

The user entering the record cannot be the only verifier.

Require verification by a second authorized user with:

certification.verify

The verifier confirms:

- CMMC UID format
- status
- dates
- C3PAO
- scope
- CAGE codes
- SSP information
- supporting record availability

Only after verification should the module state change from:

VERIFICATION_PENDING

to:

CONDITIONAL_L2_C3PAO
or
FINAL_L2_C3PAO

Provide a Global Admin override only with required justification and audit logging.

4. CMMC UID VALIDATION
====================================================================

Validate the CMMC UID as 10 alphanumeric characters.

Store it normalized in uppercase.

Do not allow duplicate active CMMC UIDs across unrelated certification records without an explicit override and justification.

Do not expose the UID publicly.

====================================================================
24. MOST IMPORTANT RULE
====================================================================

The Certification module is hidden until an organization’s official status is entered and independently verified.

The module must preserve official records and support ongoing sustainment.

It must not:

- certify an organization
- create an official government status
- submit to SPRS without an authorized integration
- automatically invalidate a status
- expose certification information publicly
- appear for uncertified organizations
