1. CURRENT DOCUMENTATION ISSUES
====================================================================

Current production problems:

1. When a file is uploaded through Documentation > Add Document, the Document record is created, but the uploaded file does not display correctly on the Document Detail page.

2. The Document Detail page displays an empty or unusable “Document Body” area instead of showing the uploaded file.

3. Uploaded documents do not consistently provide working:
   - Preview
   - View File
   - Download File

4. The purpose of the “Activate” button is unclear.

5. A document can be linked to one or more controls, but the Documentation module does not clearly explain or display those links.

6. The All Documents count does not match the Evidence Repository count, which creates confusion.

7. All Documents combines standalone uploaded documents and evidence-derived document records, but the page does not clearly explain the sources.
