Add a full Help Center / FAQ / User Guide module to Control HUB.

Goal:
Users need built-in help so they can understand how to use the system without asking an admin every time.

The Help Center should explain:
- what each module does
- how to use the system
- how to complete common workflows
- what roles can and cannot do
- how to upload evidence
- how to use controls, documentation, SSP, monitoring, POA&M, reports, pre-assessment, and roadmap features

9. Role-Based Help

Help content should adapt by role.

Examples:
- Assessor Read-Only users should see help for reviewing evidence/reports, not help for uploading/editing.
- IT Contributors should see evidence and monitoring help.
- Global Admins should see user/security/settings help.
- Demo users should see public demo guidance only.
