Repair, complete, and make package-aware ONLY the Control HUB Documentation module.

I provided a video demonstrating the current behavior.

Current observed problems:

1. Documentation Overview says users can choose from 67+ CMMC Level 2 templates, regardless of the selected organization’s active compliance packages.

2. Template Library displays:
   “CMMC Level 2 document templates — 67 templates”
   even when an organization may be CMMC Level 1 only.

3. Clicking a category card such as Policies, Procedures, Standards, Plans, Assessments & Reports, or Matrices & Registers opens the full Template Library instead of applying the selected category filter.

4. The Overview shows a four-step workflow, while Generate Document uses six steps. The terminology is inconsistent.

5. Template Detail displays raw Markdown source to normal users instead of a professional sample-output preview.

6. Generate Document allows unresolved placeholders to proceed to final generation.

7. Generated documents visibly retain unresolved placeholders such as:
   {{ACCESS_REVIEW_FREQUENCY}}
   {{MALWARE_SCAN_FREQUENCY}}

8. The generated-document detail page displays raw Markdown inside a dark “Document Body” panel instead of showing a rendered document preview.

9. Submit for Review asks for a free-text “Reviewer ID,” does not reliably submit, and produces only:
   “Action failed”

10. There is no complete document-review lifecycle:
    - no actual reviewer assignment
    - no review queue
    - no approve action
    - no request-changes action
    - no resubmission workflow
    - no meaningful review history

11. Some generated documents may display both Level 1 and Level 2 control links. Documents must only be mapped to requirements that are applicable to the selected organization and template.

Goal:

Create a professional, package-aware Documentation Center where:

- CMMC Level 1 organizations see Level 1/FCI templates
- CMMC Level 2 organizations see Level 2/CUI templates
- category cards open filtered template results
- required placeholders cannot remain unresolved
- generated documents display as rendered DOCX/PDF documents
- the review workflow actually works
- generated documents remain linked to applicable controls through the existing Evidence architecture

38. MOST IMPORTANT RULES
====================================================================

1. Template availability must be based on the selected organization’s active compliance packages.

2. A CMMC Level 1-only organization must not receive Level 2/CUI documentation templates.

3. Category cards must open the selected category, not the full unfiltered library.

4. Required unresolved placeholders must block generation.

5. Normal users must see a rendered document, not raw Markdown source.

6. Submit for Review must create a real review request and status transition or remain hidden until functional.

7. Generated documents must be stored once and linked only to applicable organization controls.
