Update the Control HUB visual theme again. The previous change is too subtle and the app still looks almost the same.

Current issue:
The sidebar looks good, but the main workspace still feels too white and flat. The page background, cards, tables, and panels blend together. I want the app to look more polished, modern, and enterprise/GRC-style.

Do not change the dark navy sidebar. The sidebar is good.

Goal:
Create a stronger “Soft Slate Enterprise Theme” for the main workspace so there is a clear visual difference between:
- app background
- page header
- cards
- tables
- panels
- content sections

This should not be full dark mode. It should be a professional soft blue-gray theme with white cards.

1. Use Stronger Main Background

Change the main content background to a more noticeable blue-gray.

Use:

--app-bg: #E8EEF6;
--app-bg-secondary: #F1F5FA;
--page-surface: #EEF3F9;
--card-bg: #FFFFFF;
--card-border: #CBD6E2;
--card-shadow: 0 8px 20px rgba(15, 23, 42, 0.06);

The current background is too close to white. Use #E8EEF6 for the main workspace.

Apply this to:
- body
- app shell
- main content wrapper
- dashboard page wrapper
- all page containers outside cards

Make sure no parent container is overriding it back to white.

2. Add a Page Header Surface

The top page header should sit on a subtle panel instead of floating on white.

For page headers, use:
- background: linear-gradient(180deg, #F8FAFC 0%, #EEF3F9 100%)
- border-bottom: 1px solid #CBD6E2
- padding: 24px 32px
- border-radius where appropriate if inside page content

For example:
“Carme Tech Compliance Dashboard” should sit on a slightly tinted header area, not pure white.

3. Make Cards Stand Out More

Cards should remain white, but with stronger visual separation.

Use:
- card background: #FFFFFF
- border: 1px solid #CBD6E2
- border-radius: 14px
- box-shadow: 0 8px 20px rgba(15, 23, 42, 0.06)

On hover:
- border-color: #94A3B8
- box-shadow: 0 12px 28px rgba(15, 23, 42, 0.09)

Apply to:
- dashboard KPI cards
- domain readiness card
- recent activity card
- implementation roadmap card
- evidence tables
- documentation cards
- control detail cards
- monitoring tracker panels
- POA&M panels
- reports panels

Audit the CSS and remove/override any hardcoded:

from full-page wrappers.

10. Add a Theme Class

Add a root class:

theme-soft-slate

Apply it to the app shell.

All layout components should use CSS variables from this theme.

Do not scatter hardcoded colors everywhere.
