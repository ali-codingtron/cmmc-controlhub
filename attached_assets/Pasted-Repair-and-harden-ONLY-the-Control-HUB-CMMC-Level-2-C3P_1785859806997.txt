Repair and harden ONLY the Control HUB CMMC Level 2 C3PAO Certification module.

I provided a video demonstrating the current workflow.

Observed problems:

1. The Certification action is displayed on organization cards for CMMC Level 1 organizations.

2. A Level 1-only organization can enter the C3PAO certification workflow even though the workflow is for CMMC Level 2 certification assessments.

3. The final step requires second-person verification even when the acting user is a Platform Global Admin.

4. Assessment Start Date is required by the backend but is not visually marked required.

5. Assessment Completion Date is required by the backend but is not visually marked required.

6. Missing date errors appear only after submission as raw internal messages such as:

   assessmentStartDate is required
   assessmentCompletionDate is required

7. The Supporting Records step does not provide an upload function. It only asks the user to confirm that a record exists and says it may be uploaded later.

8. The current action is named Initiate Certification. Control HUB does not initiate or issue official certification; it records an official status already received through the C3PAO process.

9. The form contains both CMMC UID and Assessment Unique ID without clearly explaining whether they are different identifiers.

Goal:

- hide the C3PAO certification workflow for CMMC Level 1-only organizations
- allow a Platform Global Admin to activate a valid record without second-person verification
- make all required fields visibly and consistently required
- provide actual secure upload and management of official certification records
- preserve every existing certification and organization record
- prevent Control HUB from implying that it issues an official CMMC status
