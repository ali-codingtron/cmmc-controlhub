Fix and polish the Bulk Download feature.

Current issues:
1. The Bulk Download wizard works, but it does not look polished or user-friendly enough.
2. When I bulk download all evidence, the ZIP creates files/folders labeled UNLINKED.
3. This is wrong because the Evidence Repository UI shows the same evidence records have linked controls.
4. The export logic is likely not using the same linked-control resolver as the Evidence Repository and All Documents pages.
5. The ZIP output needs to be cleaner and more C3PAO-friendly.

Do not simply hide the word UNLINKED. Fix the underlying linked-control mapping issue.

====================================================================
1. FIX LINKED CONTROL EXPORT BUG
====================================================================

The Evidence Repository and All Documents pages already show linked controls correctly.

The Bulk Download export must use the same linked-control data source/resolver as those UI pages.

Create a shared backend helper:

resolveArtifactControlLinks(record)

It should support all source types:

- Evidence records
- Uploaded documents
- Generated documents
- Document-like evidence
- Reports
- SSP exports
- Monitoring evidence
- POA&M evidence

The resolver should return:

- all linked controls
- primary control
- domain code
- domain name
- CMMC level
- control title

Do not rely only on a file record or attachment record.
The file itself may not have the control link.
The parent evidence/document record may have the link.

2. Evidence Linked Control Logic

For evidence records, linked controls should come from the same relationship table/API used by the Evidence Repository UI.

If Evidence Repository shows:

AC.L1-3.1.1

then Bulk Download must also export the file as linked to:

AC.L1-3.1.1

The ZIP filename must not say UNLINKED.

3. Document Linked Control Logic

For All Documents, linked controls may come from different sources:

- generated document control mappings
- uploaded document control mappings
- document-like evidence control mappings
- source evidence record mappings

If All Documents shows a linked control, Bulk Download must include that same linked control in:

- exported filename
- folder path
- File_Index.xlsx
- Control_Mapping.xlsx

4. Fix Filename Generation

Current bad example:

UNLINKED__Policy__3.13.4_Policy__2026-05-05.txt

Correct format:

SC.L2-3.13.4__Policy__3.13.4_Policy__2026-05-05.txt

or if multiple controls:

SC.L2-3.13.4_PLUS_2_CONTROLS__Policy__3.13.4_Policy__2026-05-05.txt

Filename rules:
- use primary linked control if one exists
- if multiple controls, use primary control plus count
- never use UNLINKED unless the artifact truly has no control mapping
- include all linked controls in the manifest
- keep filenames under 120 characters
- preserve original file extension
- remove unsafe filename characters
- append _01, _02 for duplicates

5. Fix Folder Placement

When ZIP structure is “By Security Domain”:

If an artifact has linked controls:
- place it under the correct domain/control folder

Example:
AC_Access_Control/
  AC.L1-3.1.1/
    AC.L1-3.1.1__Report__VTCCORPUS_All_Users__2026-07-06.csv

If artifact has multiple linked controls:
- place it under the primary control folder
- include all linked controls in Control_Mapping.xlsx

Optional:
- allow “copy to every linked control folder” checkbox

If artifact truly has no linked controls:
- do not place it in normal domain folders
- put it in:
  00_Unmapped_Needs_Review/

But only if the user chooses:
Include unmapped items

Default:
Exclude unmapped items from C3PAO-style exports unless explicitly included.

7. Production Backfill / Repair Tool

Add admin-only tool:

Admin > Data Maintenance > Repair Artifact Control Links

For VTCCORP.US only initially.

Dry run first.

Dry run should show:
- evidence records with missing export control mappings
- documents with missing export control mappings
- document-like evidence that should be mapped
- records where control can be inferred from title/metadata
- records where control cannot be inferred

Repair rules:
A. If Evidence Repository already shows linked controls:
- use that relationship as source of truth
- repair export mapping/resolver, not necessarily data

B. If title contains a clear control reference:
Examples:
3.13.4
AC.L1-3.1.1
SI.L2-3.14.7
- suggest mapping to matching control
- require admin confirmation before writing

C. If record has no control link and cannot be inferred:
- mark as Unmapped / Needs Review
- include in Export_Issues.xlsx

Do not automatically guess mappings without confirmation.

17. Permission Handling

All roles that can normally download evidence/documents should be able to use bulk download.

But bulk download must respect existing permissions.

Assessor Read-Only:
- can bulk download only records they can view/download individually
- default statuses should be Approved, Active, Assessor Ready
- cannot include Draft/internal-only files unless explicitly permitted

Global Admin/Org Admin/Compliance Manager:
- can include more statuses if selected
