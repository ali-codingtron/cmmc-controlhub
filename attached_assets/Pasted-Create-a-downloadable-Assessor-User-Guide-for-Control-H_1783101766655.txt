Create a downloadable Assessor User Guide for Control HUB specifically for the Assessor Read-Only role and the production VTCCORP.US organization.

Purpose:
We are preparing for an audit and I need to provide the assessor with clear instructions on how to use Control HUB during the review.

The guide must explain:
- how the assessor logs in
- what the assessor can view
- what the assessor cannot change
- how to navigate VTCCORP.US
- how to review controls
- how to find evidence
- how to preview/download evidence
- how to review SSP mappings
- how to review monitoring records
- how to review POA&M items
- how to use reports
- how to ask for help if they cannot find something

The guide must include screenshots from the actual app experience.

Important:
This guide is specifically for the Assessor role, not Admin, Compliance Manager, or IT Contributor.

The guide must not include admin-only instructions like:
- adding users
- editing controls
- uploading evidence
- changing statuses
- deleting evidence
- running tenant scans
- changing settings
- connecting Microsoft tenants

The assessor role is read-only.
