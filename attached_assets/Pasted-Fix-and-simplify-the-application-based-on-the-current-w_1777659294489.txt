Fix and simplify the application based on the current workflow issues. Do not add unrelated features.

1. Expand Bulk Upload Evidence Modal
The bulk upload modal is too small and cramped.

Update it so:
- modal is wider and taller
- table is readable without excessive horizontal scrolling
- columns fit properly
- action buttons are always visible
- selected files table supports scrolling inside the modal
- metadata fields are cleanly laid out

2. Add Bulk Status Update on Control Evidence Tab
On each control’s Evidence tab, add bulk actions for linked evidence.

Requirements:
- Add checkboxes next to each evidence item
- Add “Select All”
- Add bulk action dropdown:
  - Change Status
  - Archive
  - Remove from Control
- For Change Status, allow selecting:
  - Draft
  - Pending Review
  - Approved
  - Active
  - Assessor Ready
  - Rejected
  - Stale
  - Superseded
  - Archived

When bulk status update is applied:
- update all selected evidence records
- update evidence cards immediately
- update counts/readiness
- write audit logs

3. Fix Back Button / Breadcrumb Behavior
The app should act like a breadcrumb trail.

Requirements:
- When I click into evidence, documents, controls, tasks, or POA&Ms, Back should return me to the exact previous page I came from.
- If I came from a control Evidence tab, Back returns to that control Evidence tab.
- If I came from Evidence Repository, Back returns to Evidence Repository with filters preserved.
- If I came from All Documents, Back returns to All Documents with filters preserved.
- Use browser history when available.
- Add visible breadcrumbs where useful:
  Organization > Controls > AC.L2-3.3.5 > Evidence > Evidence Title
