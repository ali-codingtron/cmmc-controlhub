16. Automation Behavior
Implement these automation rules:

- When a policy is generated, link it to its mapped controls
- When a procedure is activated, create recurring task rules
- When a recurring log is completed, create an evidence item automatically
- When a document is approved, make it available in assessor view
- When a document passes its review date, mark it needs_update
- When a document expires, mark it expired and create a review task
- When a control has no active policy, show it as missing documentation
- When a control has no active procedure, show it as missing procedure
- When a recurring compliance task is completed, generate a review log
- When a checklist is completed, create evidence and link it to the correct controls
- When a document is superseded, retain prior version history
- When a document is edited, create a new document version
- When a document is approved, record approver, approval date, and version
- When a generated log is approved, update the linked control’s evidence status
