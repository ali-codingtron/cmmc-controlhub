6. Connection Flow

After environment variables are configured:

- User clicks Connect Microsoft Tenant
- App builds Microsoft admin consent URL using MICROSOFT_CLIENT_ID and MICROSOFT_REDIRECT_URI
- User is redirected to Microsoft
- Tenant admin signs in directly with Microsoft
- Tenant admin grants consent
- Microsoft redirects back to Control HUB callback
- Control HUB validates state
- Control HUB stores tenant connection metadata
- Tenant appears as Connected
